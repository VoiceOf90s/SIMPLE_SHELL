# SimpleShell

Простой интерпретатор командной строки (оболочка) на C++, реализованный с использованием системных вызовов POSIX. Проект демонстрирует понимание основ работы операционных систем, управления процессами и чистого архитектурного подхода.

## Технологии

1. Язык: C++ (стандарт C++17)
2. Система сборки: CMake (версия 3.10+)
3. API: POSIX API (fork, execvp, waitpid, chdir)
4. Платформа: Linux, macOS (или любая другая POSIX-совместимая система)

## Как запустить

### Требования
1. Компилятор C++ (GCC/G++ или Clang)
2. Система сборки CMake
3. POSIX-совместимая операционная система

### Инструкция

1.  Клонируйте репозиторий:
    git clone github.com/VoiceOf90s/SIMPLE_SHELL
    cd SIMPLE_SHELL

2.  Сконфигурируйте и соберите проект с помощью CMake:
    mkdir build
    cd build
    cmake ..
    make

3.  Запустите оболочку:
    Исполняемый файл SimpleShell будет находиться в директории build.
    ./SimpleShell

    Теперь вы можете вводить команды, например: ls -l, echo hello world, pwd. Для выхода введите exit или нажмите Ctrl+D.

## Чему я научился

Разработка этого проекта позволила мне глубоко погрузиться в системное программирование и укрепить ключевые навыки:

1. Управление процессами: Я освоил классический цикл fork-exec-wait, который является фундаментом для запуска программ в Unix-подобных системах. Я понял разницу между родительским и дочерним процессами и научился управлять их взаимодействием.

2. Работа с системными вызовами: Проект потребовал прямого использования низкоуровневых функций POSIX API, таких как fork, execvp, waitpid и chdir. Это дало мне практический опыт взаимодействия с ядром операционной системы.

3. Архитектура и абстракция: Я спроектировал систему с четким разделением ответственности: Parser отвечает только за разбор строки, Executor — за выполнение команд (как встроенных, так и внешних), а Shell — за основной цикл и взаимодействие с пользователем. Это делает код масштабируемым и легким для понимания.

4. Интероперабельность C++ и C API: Я столкнулся с необходимостью преобразования современных C++ типов (std::string, std::vector) в C-style массивы (char*[]), требуемые POSIX API. Это ценный опыт, часто встречающийся в реальных проектах, где нужно интегрироваться с унаследованными или системными библиотеками.

5. Надежная обработка ошибок: Я научился проверять код возврата каждого системного вызова и использовать perror для вывода понятных системных ошибок, что критически важно для отладки системного ПО.
